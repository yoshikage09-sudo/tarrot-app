# 統合タロット占いアプリ PWA版

## 中身
- index.html
- manifest.json
- service-worker.js
- icons/

## スマホに入れる方法
1. このフォルダをHTTPSで公開できる場所に置きます。GitHub Pages / Netlify / Vercel などで大丈夫です。
2. スマホのChromeまたはSafariで公開URLを開きます。
3. Android Chromeなら「アプリをインストール」または「ホーム画面に追加」を選びます。
4. iPhone Safariなら共有ボタンから「ホーム画面に追加」を選びます。

## 注意
HTMLファイルをスマホで直接開くだけでは、PWAとして認識されない場合があります。
PWAとして入れるには、基本的にHTTPS配信が必要です。
